# Southern Flow Plumbing

A simple static website built from Southern Flow Plumbing's public Instagram branding and project photography.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

## Local preview

Serve the `site` folder with any static web server, then open the local URL in a browser.

## Deployment

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes the contents of `site` to GitHub Pages whenever the `main` branch is updated.
